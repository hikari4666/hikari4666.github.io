Hikari Agent（小光）

A single-user, personal AI assistant — 個人自用的 AI 助理

What this app is / 這是什麼

Hikari Agent is a personal automation assistant operated by one individual for their own use. It connects to that person's own Google account through OAuth 2.0 so the assistant can read and send email, check and create calendar events, and read documents and spreadsheets when the owner asks it to. There is no sign-up, no public user base, and no third-party customers — the only user is the account owner.

本應用為個人自用的自動化助理，僅供單一使用者（帳號本人）操作自己的 Google 帳號。 透過 OAuth 2.0 授權後，助理可在本人要求下讀取與寄送 Gmail、查詢與建立日曆行程、 讀取文件與試算表。本應用不開放註冊、沒有其他使用者，也不對外提供服務。

How it works / 運作方式

  • Authorization happens once, through Google's standard consent screen.
  • The resulting OAuth token is stored locally on the owner's own machine.
  • All API calls go directly from that machine to Google's APIs — no intermediary server.
  • Access can be revoked at any time from the Google Account permissions page.
