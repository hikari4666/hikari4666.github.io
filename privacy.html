Privacy Policy — Hikari Agent

Last updated: 2026-10-28

Hikari Agent ("the app") is a private, single-user automation tool. It is operated by, and used exclusively by, the owner of the Google account that authorizes it. This policy explains what the app accesses through Google APIs and what happens to that data.

1. What the app accesses

With the owner's explicit consent, the app may access the owner's own Google data:

  • Gmail — read messages, send messages, and manage labels (scopes: gmail.readonly, gmail.modify, gmail.send)
  • Google Calendar — list, create, and delete events (calendar)
  • Google Drive — read-only file search (drive.readonly)
  • Google Sheets — read and write spreadsheets (spreadsheets)
  • Google Docs — read-only document content (documents.readonly)
  • Contacts — read-only contact list (contacts.readonly)

2. How the data is used

Data is used only to carry out tasks the owner asks for in conversation — for example summarising an email, drafting a reply, checking the calendar, or reading a spreadsheet. The app does not use Google user data for advertising, profiling, credit assessment, or training machine-learning models.

3. Where the data goes

  • The OAuth token is stored as a local file on the owner's own computer.
  • API requests go directly from that computer to Google's servers. There is no intermediate server operated by the app.
  • Data is not sold, rented, or shared with third parties, except where the owner explicitly asks the app to send an email or share a document.
  • Content may be processed by the owner's chosen AI model provider in order to generate a response; that is the owner's own configuration and account.

4. Storage and retention

The app keeps no server-side database. Conversation context exists only in local session files and local memory notes, both on the owner's machine, and can be deleted at any time.

5. Revoking access and deletion

The owner can revoke the app's access at any time at myaccount.google.com/permissions, or by deleting the local token file. Once access is revoked, the app can no longer read or modify any Google data. Any local copies of derived content (summaries, notes) can be deleted by the owner directly.

6. Security

Access is limited to a single Google account, transported over HTTPS, and the token is stored with local file permissions on the owner's machine. The app does not ask for, or store, the account password.

7. Changes

Any material change to this policy will be published on this page with an updated date.
